# AuraMarket — Enterprise Multi-Vendor Marketplace Platform

A production-ready, high-performance Multi-Vendor E-Commerce Platform engineered with Node.js, Express, React, Tailwind CSS, and Flutter.

## 🚀 Live Showroom & Interactive Portals
- **Live Demo URL:** [https://shribalajikripadham.online/ecommerce-demo/](https://shribalajikripadham.online/ecommerce-demo/)
- **Repository:** [https://github.com/ankit261194/ecommerce-demo](https://github.com/ankit261194/ecommerce-demo)

## 👑 4 Independent Portals
1. **Customer Web Storefront & PWA:** Multi-vendor cart with isolated sub-order splitting, category filters, instant checkout (COD & UPI), and secret 4-digit handover OTP.
2. **Super Admin Control Center:** Lifetime gross revenue metrics, platform commission fee controls, vendor KYC verification, double-entry financial ledger, and 1-click showroom seed/wipe.
3. **Vendor / Seller Management Portal:** Product catalog with multi-variant SKUs, store-specific order fulfillment slips, status steppers, and bank payout requests.
4. **Courier & Logistics Delivery Hub:** Field task pickup & drop navigation, COD cash collection, and 4-digit OTP customer handover verification.
5. **Flutter Mobile Apps:** Cross-platform native Android & iOS codebases.

## 🛠️ Automated Deployment
Whenever changes are pushed to the `main` branch, Hostinger Git Auto-Deployment Webhook pulls the latest build into `public_html/ecommerce-demo/`.
