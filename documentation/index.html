🚀 6. One-Time VPS Server & Domain Deployment (Module A)

🛠️ DEVELOPER REQUIRED / डेवलपर आवश्यक
🇺🇸 Why a Developer is Needed (English)

Setting up a custom domain on a Linux VPS (Hostinger KVM, AWS EC2, DigitalOcean, Ubuntu 22.04 LTS) requires root SSH commands, configuring DNS A-records, installing Node.js 20 & MongoDB, running PM2 process daemon for 24/7 uptime, configuring Nginx as a reverse proxy, and obtaining free SSL certificates via Certbot.

🇺🇸 Step 3: Nginx Reverse Proxy Config

Create configuration file /etc/nginx/sites-available/auramarket:

server {
    server_name yourdomain.com www.yourdomain.com;

    location / {
        root /var/www/auramarket/frontend/dist;
        try_files $uri $uri/ /index.html;
    }

    location /api {
        proxy_pass http://127.0.0.1:5000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}

Enable & reload: sudo ln -s /etc/nginx/sites-available/auramarket /etc/nginx/sites-enabled/ && sudo nginx -t && sudo systemctl restart nginx

💾 8. Database Auto-Backups & Server Maintenance (Module F)

🛠️ DEVELOPER REQUIRED / डेवलपर आवश्यक
🇺🇸 Why a Developer is Needed (English)

To safeguard your store catalog, user orders, and vendor wallets against disk crashes or human errors, a developer configures a daily automated Linux cron job that runs mongodump at 2:00 AM, compresses the database archive, automatically purges backups older than 30 days, and logs results.

🇮🇳 डेवलपर की जरूरत क्यों होगी? (हिंदी)

डेटाबेस का ऑटो-बैकअप हर रोज़ रात 2:00 बजे अपने आप चलना चाहिए ताकि कभी भी सर्वर खराब होने पर आपका 1 सेकंड का भी डेटा न खोए। इसके लिए Linux Crontab में mongodump ऑटोमैटिक बैकअप स्क्रिप्ट लगानी होती है।

root@auramarket-vps:~ (crontab & backups) Automated Cron
root@auramarket-vps:~# crontab -l
# Daily Nightly AuraMarket Database Snapshot at 02:00 AM
0 2 * * * /usr/local/bin/backup-auramarket.sh >> /var/log/auramarket-backup.log 2>&1
root@auramarket-vps:~# ls -lh /var/backups/mongodb/
-rw-r--r-- 1 root root 42M Oct 13 02:00 auramarket_2026-10-13_020000.gz
-rw-r--r-- 1 root root 41M Oct 12 02:00 auramarket_2026-10-12_020000.gz
-rw-r--r-- 1 root root 39M Oct 11 02:00 auramarket_2026-10-11_020000.gz
root@auramarket-vps:~# tail -n 2 /var/log/auramarket-backup.log
[2026-10-13 02:00:14] SUCCESS: MongoDB backup completed (42 MB). 0 errors.
🇺🇸 Automated Backup Shell Script

Save to /usr/local/bin/backup-auramarket.sh:

#!/bin/bash
BACKUP_DIR="/var/backups/mongodb"
DATE=$(date +%Y-%m-%d_%H%M%S)
mkdir -p $BACKUP_DIR
mongodump --uri="mongodb://127.0.0.1:27017/auramarket" --archive="$BACKUP_DIR/auramarket_$DATE.gz" --gzip
# Auto-delete archives older than 30 days
find $BACKUP_DIR -type f -name "auramarket_*.gz" -mtime +30 -exec rm {} +
echo "[$(date)] SUCCESS: MongoDB backup completed: auramarket_$DATE.gz"

Make executable: sudo chmod +x /usr/local/bin/backup-auramarket.sh

🇮🇳 डेटाबेस रीस्टोर कैसे करें (10 Seconds Restore)

अगर कभी सर्वर बदलना पड़े या पुराना डेटा वापस लाना हो, तो बस यह 1 कमांड चलाएं:

mongorestore --uri="mongodb://127.0.0.1:27017/auramarket" \
  --archive="/var/backups/mongodb/auramarket_LATEST.gz" \
  --gzip --drop

पूरा डेटाबेस 10 सेकंड में हूबहू रीस्टोर हो जाता है!

14. 4-Digit Secret Delivery OTP System

How AuraMarket prevents delivery fraud and ensures customer satisfaction:

  1. When a customer places an order, the backend generates a cryptographic 4-digit secret delivery OTP (e.g. 4821).
  2. This OTP is displayed only on the customer's order receipt and SMS/WhatsApp confirmation.
  3. Neither the vendor nor the courier rider can see the OTP.
  4. When the rider reaches the customer's doorstep, the customer shares the code.
  5. The rider enters the code into the Courier Hub (/api/delivery/tasks/:id/verify-otp).
  6. Only upon matching does the system update the task to DELIVERED, credit the vendor's wallet, and record the ledger entry. Direct status manipulation without OTP is strictly rejected with HTTP 400!
